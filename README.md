###### 》》 LegionUHD est un framework HUD tactique conçu pour Android + Termux. Inspiré des interfaces militaires modernes (FÉLIN, Ghost Recon)il offre une expérience minimaliste, rapide, lisible et orientée mission.
# 📘 LegionUHD
- – Tactical HUD Framework
   - v6.0 Stable

### 🎯 Objectifs
- Interface HUD cohérente et immersive
- Scripts Termux tactiques (ULTRA, Ghost, Blackout)
- Gestes optimisés pour Niagara Launcher
- Icônes monochromes HUD
- Monitoring système en temps réel
- Installation automatique via install.sh

---

### 📦 Structure du projet

```text
LegionUHD/
├── docs/               Documentation du projet
├── config/             Couleurs, layout, gestes
├── termux/             Scripts ULTRA + MOTD
├── assets/             Icônes + wallpapers HUD
└── README.md           Documentation principale
```

### ⚙️ Installation

1. 》》 Cloner le dépôt
```bash
git clone https://github.com/teremuhamblin/LegionUHD
cd LegionUHD
```

2. 》》 Lancer l’installateur
```bash
bash install.sh
```

3. 》》 Activer le HUD
```bash
legionuhd
```

### 🛡️ Modes tactiques

》》 Mode ULTRA
- Monitoring CPU/RAM
- Scanner réseau léger
- HUD animé
- Logs tactiques

》》 Mode Ghost
- Réseau silencieux
- HUD minimal
- Anonymisation locale

》》 Mode Blackout
- Silence total
- Terminal sans retour
- Opérations furtives
