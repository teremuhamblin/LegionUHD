# LegionUHD
```text
LegionUHD est un mini-projet tactique inspiré des HUD militaires.
Il fournit une identité visuelle, un thème, un script Termux et une
structure adaptable pour launcher Android ou projet GitHub.
```

### Contenu
```text
- Palette militaire HUD
- Layout minimaliste
- Gestes tactiques
- Script Termux d’initialisation
- Assets visuels (fond d’écran + icônes)
```

### Usage
```text
Ce projet sert de base pour créer un environnement mobile militaire,
discret, optimisé et fonctionnel.
```
