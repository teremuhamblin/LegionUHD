# LegionUHD — Layout Tactique

Le layout LegionUHD est conçu pour reproduire un HUD militaire moderne :
minimaliste, lisible, orienté mission, optimisé pour Niagara Launcher et Termux.

---

## 🎯 Objectifs du layout
- Affichage clair des informations essentielles
- Navigation rapide et gestuelle
- Zéro distraction visuelle
- Optimisation pour écrans mobiles (Android)
- Compatibilité totale avec LegionUHD ULTRA

---

## 🧩 Structure générale

### 1. **HUD supérieur (Top HUD)**
- Heure (format 24h)
- Météo minimaliste
- Indicateurs système :
  - Batterie
  - Réseau
  - Température CPU
  - Uptime

### 2. **Bloc central**
Organisation en trois groupes tactiques :

#### **OPS (Opérations)**
- Téléphone
- Messages
- Appels
- Agenda

#### **INTEL (Renseignement)**
- Navigateur sécurisé
- Notes
- Cartes
- Recherche

#### **SYSTEM (Système)**
- Paramètres
- Termux
- Gestionnaire de fichiers
- Sécurité

### 3. **HUD inférieur (Bottom Line)**
- Ligne système dynamique :
  - CPU %
  - RAM %
  - Ping
  - IP locale
  - Mode actif (Normal / Ghost / Blackout)

---

## 📱 Optimisation Niagara Launcher
- Liste d’apps verticale centrée
- Gestes tactiques (voir gestures.md)
- Icônes monochromes LegionUHD
- Fond d’écran HUD sombre
- Animations réduites

---

## 🔧 Compatibilité Termux
- Affichage MOTD LegionUHD
- Scripts ULTRA (monitoring + modes)
- Palette HUD synchronisée avec colors.json

---

## 🛡️ Mode Mission
- Affichage minimal
- Icônes réduites
