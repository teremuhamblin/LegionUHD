# LegionUHD — Gestes Tactiques

Les gestes LegionUHD sont inspirés des interfaces militaires FÉLIN / Ghost Recon.
Ils permettent une navigation rapide, silencieuse et optimisée.

---

## 🎯 Objectifs
- Accès instantané aux modules critiques
- Réduction des mouvements
- Fluidité opérationnelle
- Compatibilité Niagara / Termux / Android

---

## 🧨 Gestes principaux

### ➤ **Swipe droite**
**Action :** Ouvrir Termux  
**Usage :** Accès direct au système, scripts ULTRA, monitoring.

---

### ➤ **Swipe gauche**
**Action :** Navigateur sécurisé  
**Usage :** Recherche, OSINT, documentation rapide.

---

### ➤ **Double-tap écran**
**Action :** Verrouillage immédiat  
**Usage :** Mode Ghost / sécurité / discrétion.

---

### ➤ **Appui long sur bouton Niagara**
**Action :** Lancer `legionuhd.sh`  
**Usage :** Initialisation HUD, services, modes tactiques.

---

## 🔧 Gestes secondaires

### ➤ Swipe bas → haut
**Action :** Panneau système  
**Infos :** CPU / RAM / Réseau / Batterie

### ➤ Swipe haut → bas
**Action :** Notifications minimalistes

### ➤ Appui long sur icône SYSTEM
**Action :** Mode Blackout (silence total)

---

## 🛡️ Modes spéciaux

### **Mode Ghost**
- Réseau silencieux  
- HUD réduit  
- Logs minimalistes  

### **Mode Blackout**
- Terminal silencieux  
- Aucun retour visuel  
- Opérations furtives  

---

## 📌 Notes
- Tous les gestes sont compatibles avec Niagara Launcher.
- Les modes spéciaux sont activés via `legionuhd.sh`.
