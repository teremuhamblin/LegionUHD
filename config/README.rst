===========================
LegionUHD – Dossier config/
===========================

Ce dossier contient les fichiers de configuration essentiels au HUD
tactique LegionUHD. Ils définissent l'apparence, la structure visuelle
et les gestes utilisés dans l'interface.

Contenu
-------

- **colors.json**  
  Palette de couleurs du HUD (indicateurs, alertes, système).

- **layout.md**  
  Organisation visuelle du HUD : zones, blocs, affichage tactique.

- **gestures.md**  
  Gestes et interactions rapides compatibles avec Niagara Launcher.

Usage
-----

Les fichiers du dossier ``config/`` sont chargés automatiquement par
les scripts LegionUHD pour assurer une interface cohérente, lisible et
optimisée sur Android + Termux.
