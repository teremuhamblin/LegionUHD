# 📂 Structure — LegionUHD

Ce document détaille la structure complète du projet.

---

## Dossier `config/`

### `colors.json`
Palette militaire HUD (vert tactique, noir opérationnel, gris acier).

### `layout.md`
Structure du HUD Android / Niagara.

### `gestures.md`
Gestes tactiques (swipe, double-tap, actions Niagara).

---

## Dossier `termux/`

### `legionuhd.sh`
Script tactique sécurisé :
- mode furtif
- vérification des binaires
- démarrage des services
- monitoring système
- nettoyage mémoire

### `motd_legionuhd.txt`
Bannière militaire ASCII.

Fond d’écran tactique.

Pack d’icônes HUD.
