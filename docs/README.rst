===========================================================
                 LegionUHD — Tactical HUD Framework
===========================================================

LegionUHD est un framework tactique inspiré des systèmes HUD
(Heads-Up Display) militaires. Il fournit une identité visuelle,
une architecture technique, un script Termux sécurisé, et une
structure adaptable pour Android, Niagara Launcher ou projet GitHub.

Ce projet vise à créer un environnement :
- discret
- optimisé
- fonctionnel
- orienté opérations

-----------------------------------------------------------
📦 Contenu du projet
-----------------------------------------------------------

- Palette militaire HUD
- Layout minimaliste
- Gestes tactiques
- Script Termux d’initialisation (sécurisé)
- Assets visuels (fond d’écran + icônes)
- Documentation complète (architecture, structure, roadmap, changelog)

-----------------------------------------------------------
🎯 Objectifs
-----------------------------------------------------------

LegionUHD permet de :

- Déployer un HUD militaire sur Android (Niagara, Hyperion, Lawnchair)
- Créer un environnement Termux tactique (scripts, MOTD, modules)
- Fournir une base visuelle pour un projet GitHub ou une application
- Standardiser un style militaire moderne, propre et fonctionnel

-----------------------------------------------------------
🚀 Usage
-----------------------------------------------------------

LegionUHD sert de base pour créer un environnement :

- mobile (launcher, thème, widgets)
- terminal (Termux, scripts, monitoring)
- logiciel (UI/UX militaire)
- GitHub (structure, documentation, identité visuelle)
